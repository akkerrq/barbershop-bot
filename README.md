# 💈 Telegram Bot: Онлайн-запись для Барбершопа (CRM System)

Асинхронный Telegram-бот на Python (`aiogram 3`) для автоматизации онлайн-записи клиентов в барбершоп или салон красоты.

## 🚀 Основной функционал

### Для клиентов:
- **Просмотр прайс-листа:** Удобное меню с актуальными услугами и ценами.
- **Интерактивная запись:** Пошаговый выбор услуги, даты и свободного времени.
- **Динамические слоты:** Автоматическое скрытие прошедших часов на текущий день и замена занятых слотов на `🔒`.
- **Личный кабинет «Мои записи»:** Просмотр своих активных броней с возможностью отмены записи через всплывающее подтверждение (**Alert**).
- **Авто-чистка:** Прошедшие записи автоматически удаляются из базы при просмотре.

### Для администрации и владельцев:
- **Админ-панель:** Ограниченный доступ по Telegram ID.
- **Управление услугами:** Добавление новых услуг и прайса прямо из интерфейса бота.
- **Наглядное расписание:** Просмотр всех броней с группировкой по блокам дат (`📅 === [ 11.08 ] ===`).
- **Уведомления:** Мгновенные оповещения админов о каждой новой записи клиента.

---

## 🛠 Технологический стек

- **Язык:** Python 3.11+
- **Фреймворк:** `aiogram 3.x` (Asyncio)
- **База данных:** SQLite + `SQLAlchemy 2.x` (Async)
- **Управление временем:** `zoneinfo` (учет часовых поясов, UTC+5)

## 📦 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com/твой-логин/barbershop-booking-bot.git](https://github.com/твой-логин/barbershop-booking-bot.git)
   cd barbershop-booking-bot

Создайте и активируйте виртуальное окружение:
    python -m venv venv
    source venv/bin/activate  # Для Linux/macOS
    venv\Scripts\activate     # Для Windows

Установите зависимости:
    pip install aiogram sqlalchemy

Настройте конфигурацию:
    Переименуйте config.py.example в config.py и укажите ваш BOT_TOKEN и ID администраторов.

Запустите бота:
    python main.py
